# ⚡ Blitz Tag  Welcome to Blitz Tag!  ## Installation  1. Download the Blitz Tag ZIP file. 2. Extract the ZIP file. 3. Open Google Chrome. 4. Visit `chrome://extensions`. 5. Turn on **Developer mode**. 6. Click **Load unpacked**. 7. Select the extracted Blitz Tag folder.   ## Download  Click the green Code button and select Download ZIP.
